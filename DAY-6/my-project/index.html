Native accordion
Why use Bootstrap’s grid?
It provides responsive containers, rows, columns, gutters, and container-query variants without writing layout CSS for every page.
What changed in Bootstrap 6?
Bootstrap 6 adds composable theme classes, native dialog and drawer components, modern Sass modules, and expanded form controls.
Does this accordion need JavaScript?
No. Bootstrap 6 styles native <details> elements, and the shared name attribute provides exclusive open-and-close behavior.
